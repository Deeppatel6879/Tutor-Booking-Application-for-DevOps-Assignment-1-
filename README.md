# Tutor Booking Application - Visual Studio 2022

## Requirements

- Visual Studio 2022
- The **ASP.NET and web development** workload
- .NET 8 SDK

## Open and run

1. Extract the ZIP file.
2. Open `TutorBookingVS2022.sln` in Visual Studio 2022.
3. Wait for Visual Studio to load the project.
4. Select the `https` run profile in the top toolbar.
5. Press the green Run button or press `F5`.
6. Accept the local HTTPS development certificate prompt if Visual Studio displays one.

The website should open automatically in your browser.

## Where to edit the website

- `TutorBookingApp/wwwroot/index.html` - page structure
- `TutorBookingApp/wwwroot/css/style.css` - styling and responsive layout
- `TutorBookingApp/wwwroot/js/booking.js` - form validation, local storage and booking functions
- `TutorBookingApp/Program.cs` - ASP.NET Core startup code
